# egovBoardStudy

전자정부프레임워크(eGovFrame)를 기반으로 게시판 구조와 MVC 흐름을 학습하기 위한 개인 프로젝트

기본 게시판 기능을 구현한 뒤 로그인, 관리자, 공지사항, 마이페이지 등의 기능을 추가하면서
Controller → Service → ServiceImpl → DAO → Mapper → DB 흐름을 학습

## 현재 구현 기능

- 로그인 / 로그아웃
- 회원가입
- 게시글 목록 조회
- 게시글 검색 및 페이징
- 게시글 등록 / 수정
- 게시글 상세 조회
- 파일 업로드 / 다운로드
- 댓글 조회 / 등록 / 수정
- 게시글 추천 / 추천 취소
- 추천수 기반 zTree 게시판 조회
- 게시판 카테고리 분류

## 앞으로 구현할 기능

### 1. 로그인 기능 보완

현재 로그인 기능을 정리하고 로그인 관련 처리 과정을 보완할 예정

- Login Controller 구조 정리
- `Logger`를 이용한 로그인 처리 로그 추가
- 로그인 성공 / 실패 로그 처리
- 예외 발생 시 로그 기록
- 현재 `printStackTrace()` 방식이 사용된 부분도 Logger 방식으로 변경
- 로그인 관련 입력값 검증 정리
- Session 처리 구조 정리
- 로그인 / 로그아웃 처리 흐름 개선

목표

```text
사용자 로그인 요청
↓
Controller
↓
입력값 확인
↓
사용자 조회
↓
로그인 성공 / 실패 판단
↓
Logger 기록
↓
Session 생성
↓
마지막 로그인 시간 갱신

결과 반환
